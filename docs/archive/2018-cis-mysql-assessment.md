abstract: >
  Uses the Center for Internet Security (CIS) benchmark report for
  Oracle MySQL Community Server 5.7 — a publicly available security
  checklist also hosted by the National Vulnerability Database and
  National Checklist Program Repository — to verify the CIS report
  against MySQL's own release notes, then evaluates both to assess
  whether the application is approved to operate at a proposed level of
  trust. Scoped to checks on logging and auditing, authentication,
  network, and replication for MySQL Server 5.7 in a personal/private
  network environment. Includes an ATO letter, configuration management
  plan, relevant change report, risk assessment, SAPT letter, and
  vulnerability and penetration test report.
